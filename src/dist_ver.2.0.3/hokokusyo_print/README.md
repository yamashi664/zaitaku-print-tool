# 報告書印刷ツール

ブラウザ版MUSUBIからダウンロードしたZIP形式の在宅報告書をドラッグ＆ドロップで読み込み、指定した薬局向けの送付状を自動生成・印刷する業務自動化ツールです。
ブラウザ版のMUSUBIのみ対応しています。アプリ版には対応していません。


## 主な機能

* **ドラッグ＆ドロップ対応**: ZIPファイルを画面に投げ込むだけで読み込み可能です。
* **送付状自動生成**: テンプレートファイル（`fax_template.docx`）に基づき、各薬局用の送付状を自動作成します。
* **送付状、報告書の印刷順選択**:プリンターの仕様に合わせて先に印刷する書類を選択できます。
* **薬局、印刷順選択の記憶**: 最後に選択した薬局を記憶し、次回起動時にデフォルトで選択状態にします。
* **一括印刷**: PDFおよび生成された送付状（Word）を、指定のプリンターで順次印刷します。

## フォルダ構成

本ツールを実行するには、配布フォルダ（`dist/`）に以下のファイルが揃っている必要があります。

.
├── hokokusyo_print.exe    # 実行ファイル
├── config.json            # 設定ファイル
├── PDFtoPrinter.exe       # PDF印刷用ツール
└── fax_template.docx      # 送付状のテンプレートファイル


## 必要な外部ツールに関して

本ツール実行に際して、Libreofficeのみ別途インストールしておく必要があります。
（通常のofficeではバックグラウンド印刷が出来ません。）


## configの設定

設定ファイルは以下の形式で記述してください。

{
  "printer_name": "プリンター名",
  "soffice_path": "soffice.exeのパス",
  "pdftoprinter_path": "PDFtoPrinter.exeのパス",
  "queue_limit": 6,
  "queue_wait_interval_sec": 1.0,
  "pharmacies": [
    {
      "pharmacy_name": "〇〇薬局 本店",
      "post_code": "〒123-4567",
      "address": "東京都...",
      "tel_num": "03-1234-5678",
      "fax_num": "03-1234-5679"
    },
    {
      "pharmacy_name": "〇〇薬局 駅前店",
      "post_code": "〒987-6543",
      "address": "東京都...",
      "tel_num": "03-5320-3333",
      "fax_num": "03-5320-3332"
    }
  ],
  "last_selected_pharmacy": "前回選択した薬局名",
  "last_print_order": "報告書→送付状"
}

printer_name: Windowsの「デバイスとプリンター」に表示されている正確なプリンター名。
soffice_path: 別途インストールしたLibreOfficeの実行ファイルパス。
pdftoprinter_path: 初期状態で相対パスを指定しているため、変更不要です。
last_selected_pharmacy: アプリが自動更新しますが、手動で初期値を設定可能です。
last_print_order:アプリが自動更新します。

## 使い方

hokokusyo_print.exe を起動します。
「1. 処理するZIPファイル」のエリアにZIPファイルをドラッグ＆ドロップするか、「ファイルを選択」ボタンで指定します。
「2. 薬局を選択」にて、送付状を出したい薬局を選びます（前回選択した薬局が自動で選ばれます）。
「3.印刷順選択」でプリンタに合わせた印刷順を選択します。
「この薬局で印刷処理を開始」ボタンを押します。
「印刷するファイルを選択」画面で印刷が必要なものにチェックを入れ印刷します。
処理完了までお待ちください。


## トラブルシューティング

起動しない/エラーが出る: config.json が exe ファイルと同じ階層にあるか確認してください。
送付状が出ない: fax_template.docx が正しい場所に配置されているか確認してください。
印刷されない: config.json 内の printer_name がWindowsのプリンター名と一致しているか確認してください。
